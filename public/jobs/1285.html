公司介绍

ParallelChain Labs (https://parallelchain-labs.com/) 是一家总部位于新加坡的 **Blockchain + AI 公司**，在新加坡、香港和泰国设有团队。 我们专注于区块链基础设施、区块链应用以及 AI 技术的研发，并持续推进实际产品和项目落地。 目前我们正在寻找一名 **Blockchain Engineer**，参与区块链产品、基础设施以及智能合约相关的开发工作。

工作内容

- 负责区块链相关产品和基础设施的开发与维护 - 使用 **Solidity / EVM** 开发和维护智能合约 - 参与 Token、Coin 及其他链上资产相关功能的开发 - 参与区块链协议及底层系统相关开发 - 开发与区块链相关的后端服务及工程工具 - 负责代码测试、Code Review，以及系统安全性和稳定性的持续改进 - 分析并解决开发及线上环境中的技术问题 - 与其他工程师一起进行技术方案设计和项目开发

我们希望你具备

- 3 年以上软件开发经验，并有实际区块链开发经验 - 熟悉 **Solidity / EVM** - 对区块链底层原理、架构和分布式系统有较好的理解 - 熟练掌握 **Rust、Go、C++、TypeScript 或 Solidity** 中至少一种 - 有生产环境软件开发经验，而不仅是 Demo 或个人实验项目 - 了解智能合约及区块链常见安全问题 - 具备较强的问题分析和独立解决能力，能够负责一个项目或模块从开发到上线

以下经验会比较加分

- **有实际 Token 或 Coin 开发、发行和上线经验** - 有 ERC-20、ERC-721、ERC-1155 等 Token 标准开发经验 - 有 Layer 1 / Layer 2 区块链开发经验 - 有 DeFi 或其他链上产品开发经验 - 有共识机制、P2P 网络或跨链相关开发经验 - 有较强的 Rust / Go 开发经验 - 有开源区块链项目贡献

薪资

**SGD 120,000–150,000 / 年** 最终薪资会根据候选人的技术能力、项目经验和所在地综合确定。 对于在**区块链底层、Token/Coin、协议开发或智能合约安全**方面有较强经验的候选人，我们可以提供更有竞争力的薪资方案。

工作方式

团队主要分布在**新加坡、香港和泰国**，因此优先考虑能够配合 **GMT+8** 工作时间的候选人。 支持 **Remote 或 Hybrid** 工作方式，具体根据候选人所在地和团队安排确定。

申请方式

请将 **CV + GitHub / LinkedIn** 发送至： **[info@parallelchain-labs.com](mailto:info@parallelchain-labs.com)** TG: @InfoParallelChainLabs 申请时建议简单介绍你参与过的区块链项目，尤其是你实际开发或上线过的 **Token、Coin、Smart Contract、Blockchain Infrastructure 或 Protocol** 项目。
